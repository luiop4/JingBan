鲸伴 v1.69 · 上手指南

1. 取得完整客户端
下载完整 EXE 安装包，按中文向导完成安装，从快捷方式打开鲸伴。
安装包包含 Python、应用依赖与 OneBot 运行组件；不含开发者数据和登录资料，本地大语音模型按需安装。
默认安装到当前用户可写目录，覆盖安装保留个人数据；升级前建议备份，并从托盘退出原程序。

2. 连接聊天模型
到“设置”填写自己的模型 API 配置。模型与在线语音按服务提供方规则计费。
QQ 图片理解需使用支持视觉的模型，当前项目配置要求 deepseek-flash。

3. 管理记忆
“长期记忆”可搜索、编辑、确认和删除，确认方式支持手动或自动。
“记忆方案”查看事件索引与整理状态，事件整理会产生正常 API 用量。
原始消息与记忆保存在本机，模型生成依然需要相应服务。

4. QQ 接入
到“QQ 接入”配置内置 OneBot 桥接并自行完成 QQ 登录。
在“聊天与联系人”维护信任名单，按需开启自动回复、语音、表情和其他能力。
在同页展开“主动聊天、跨端同步与权限细节”，手动填写本人 QQ 并保存。
绑定后两端合并读取近期对话，可按范围检索历史、图片、事件和有来源的长期记忆。
可单独开启客户端工具任务结果通知。普通闲聊不全部转发。
鲸伴和 QQ 桥接须保持运行，无需额外部署记忆服务器。

5. 鲸鱼心跳
从主侧栏打开“鲸鱼心跳”，查看总览、兴趣范围、心事匣、素材池、打算账本与运行记录。
打算和未完想法持续保留；可以继续考虑、暂放或放下。
素材池可按类型与关键词搜索，并查看真实来源及已有截图。
主动活动需软件保持运行和相应模型配置，电脑操作仍需独立开启并沿用原批准方式。
在“节律与权限”按需开启能力，不需要时可暂停。

6. 普通模式与工作模式
聊天输入框上方切换，自动保存，重启后恢复。
普通与工作模式的近期对话、输入草稿分别保留，长期记忆、事件与历史检索共用。
普通模式沿用角色与原有主动活动设置；工作模式专注当前任务，暂缓自动心跳、自动视频、QQ主动搭话与自主动态。
手动指令仍按原权限使用，记忆、角色和QQ绑定继续保留，切回普通模式沿用原设置。

7. 联网更新
v1.54启动器会展示更新内容，选择“立即更新”后才下载，也可“本次跳过”。
下次正常打开仍检查；连接失败或检查约6秒超时后尝试启动本地软件。
下载可取消；旧版启动器需先完成一次升级才具备这些新交互。
网站完整包版本与最新软件版本分别显示，请以下载页为准。

8. DSH聊天迁移
设置 → 数据迁移 → 从DSH迁移聊天记录。
选择sessions目录或支持的Session日志ZIP、JSONL、结构化JSON，先核对预览再导入。
导入前自动备份，追加并去重，不覆盖当前鲸伴数据。
图片与文件完整迁移建议使用含附件的日志ZIP；实际支持以预览识别结果为准。
导入本身不调用模型；默认在历史记录中查询，不立刻整理全部旧记录。

9. 浏览与活动
从“鲸鱼心跳 → 浏览与活动”管理浏览能力。
需要沿用已有B站登录时，点“接入已登录的浏览器”，按说明在原浏览器安装连接扩展。
后台读网页、B站后台评论与点赞和实际播放器控制分别处理；登录、账号权限与站点限制仍适用。
自主选片参考持续兴趣和真实见闻，不需要填写固定选题词。可以保存关闭不需要的能力。

10. 会话迁移
到“设置 → 会话与记忆 · 导出 / 导入备份”管理迁移。
迁移包不含 API 配置、QQ 令牌、运行环境和本地语音模型，新电脑需重新配置。

11. 托盘和开机启动
设置中可按需开启登录后驻留托盘。安装不会默认替你开启。
托盘驻留后，关闭聊天窗口仍可能继续运行；需要完全退出时，右键托盘选择“退出鲸伴”。

本指南依据项目 v1.69，2026 年 10 月 29 日。
