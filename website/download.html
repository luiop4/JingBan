BEFORE YOU BEGIN

准备好，再出发。

已有客户端，如何更新？＋

先备份会话与记忆，并从托盘退出鲸伴，再运行新版完整安装包，选择原安装目录进行覆盖安装。也可使用启动器检查联网更新；安装包与联网更新通道独立发布，请以各自显示的版本为准。启动器支持查看更新说明、本次跳过及下载取消。

安装和卸载会怎样处理个人数据？＋

纯净安装包不包含开发者数据库、密钥、QQ 或浏览器登录资料及用户插件。覆盖安装保留个人设置；卸载保留用户生成的数据和登录资料。仍建议先备份重要会话。安装不会默认替你开启开机自启动。

可以直接从旧电脑搬过来吗？＋

在旧电脑通过「设置 → 会话与记忆 · 导出 / 导入备份」导出，再在新客户端导入。迁移包不含模型 API 密钥、QQ 令牌、运行环境与本地语音模型，需要重新配置相应服务。

本地语音是否已经包含？＋

此纯净包不预装本地 Qwen 环境和模型。可先使用已配置的在线语音，之后在客户端按需安装本地语音。
