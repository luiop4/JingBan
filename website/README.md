# 鲸伴宣传网站

[← 返回项目首页](../README.md)

这里保存当前宣传网站的公开静态文件，可用任意静态服务器预览 `index.html`，下载入口为 `download.html`。

截图来自 v1.47 的独立演示数据库，未携带个人数据。功能宣传按原网站保留，源码当前为 v1.75；页面读取远程版本和完整包元数据，完整包版本与源码版本分别发布。

`release.json` 保存网站实际发布过的安装包版本、公开链接、文件大小及摘要。后续发布需先上传并核验真实安装包，再更新元数据；不要仅随源码版本改写安装包版本。

此目录不包含安装包、网站服务端配置、部署历史或登录资料。
